# La Cosecha website

A static website using your supplied logo and group photo. No installations, subscriptions, or build tools are needed. Open `index.html` to preview it.

## Publish with GitHub Pages

1. Create a public GitHub repository named `la-cosecha`.
2. Extract this ZIP. Upload the contents of the `la-cosecha` folder to the repository root: `index.html`, `style.css`, and the `images` folder. Upload the files, rather than the ZIP itself.
3. In the repository, open Settings → Pages. Under Build and deployment, select Deploy from a branch, then `main` and `/ (root)`. Save.
4. GitHub will display your website link when deployment finishes.

## Customize

- Instagram is linked to https://www.instagram.com/lacosechaorg/ throughout the site.
- Board names, roles, and headshots have not been supplied. Add member cards at the commented example in `index.html`.
- Past health fairs are highlighted with six supplied photos and descriptions of screenings, education, giveaways, and resource tables. Specific event dates and names can be added when available.
- No email was supplied. Add an email link to the contact section when available, using `<a href="mailto:YOUR_EMAIL">YOUR_EMAIL</a>`.
- The mission is lightly edited for readability while retaining its meaning.
- The original outdoor group photo is in the hero. The new indoor group photo is in Our community in action.
- To update the site later, edit the relevant file in GitHub and commit the change. Pages will publish the update.

## Board example

Copy the commented board-grid example in index.html, remove the surrounding HTML comment, then replace the sample name, role, and image filename with actual member information. Add photos to images/. Duplicate each article for additional members.
